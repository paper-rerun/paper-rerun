What is here, and what is not.

file_list.txt is the directory tree that ships inside the release, copied unchanged.

The release itself is not in this repository. It is one file, chains.zip, 649.5 MB, from

  https://doi.org/10.5281/zenodo.8091568
  md5 b3180fb1e8560a875fa3de5be001c4aa
  CC BY 4.0, no login and no terms to accept

Download it there and the scripts in ../scripts/ run against it as they stand: they read
the tarballs straight out of the zip. The three tarballs the frozen claims need unpack to
165 MB, which is also not here.

The paper itself is not in this repository either. It is the publisher's, and the arXiv
source we read the tables from is at arxiv.org/abs/2306.16214.
